# Token Meter

AI コーディング系サブスク（Claude Code / Codex）のトークン使用量を **API 従量課金に換算した金額**で表示する
Windows 向けデスクトップアプリです。定額プランでどれだけ元が取れているかを、GUI で条件を変えながら確認できます。

## 主な機能

- **ダッシュボード** — API 換算額、元取り倍率、トークン数、キャッシュによる節約額、リクエスト数。
  期間・サービス・モデル・プロジェクト・セッションで絞り込み、モデル別／サービス別／プロジェクト別の推移、
  曜日 × 時間帯のヒートマップ、Claude Code と Codex の比較、Codex の使用枠（最新ログ時点）を表示
- **明細** — 日・週・月・セッション・プロジェクト・モデル・サービス単位の表。並べ替え、検索、CSV 書き出し
- **元取り分析** — 契約プランを登録すると、請求サイクルごとに支払額と API 換算額を比較。
  今サイクルの累計ペースとサイクル終了時の予測も表示。Codex のログからプランの変化を検出
- **価格表** — 使用中モデルの単価と出典を一覧表示。単価の上書き、別モデルの価格の適用、
  LiteLLM からの最新価格の取得、内蔵価格と LiteLLM の差異の表示
- **設定** — ログの場所の追加（WSL や同期フォルダなど）、削除されたログの履歴保持、円／ドル表示と為替レートの自動取得、
  テーマ、自動更新の間隔

## 計算方法の要点

- Claude Code は 1 つの応答が複数行に分かれて記録され、出力トークン数は後の行ほど大きくなります。
  同じ `message.id` / `requestId` の行をまとめ、最終的な値を採用しています。
- Codex は応答ごとの `token_usage_record` を優先し、それがない古いログは `token_count` の累計差分から求めます。
  入力に含まれるキャッシュ分は分離して計算します。
- 複数のファイルに現れる同じリクエストは 1 回だけ数えます。
- Claude Code は既定で 30 日より古いログを削除しますが、このアプリは集計結果をキャッシュに保持するので、
  使い始めてからの履歴は削除後も残ります。
- 単価は Anthropic の公式価格（内蔵）と LiteLLM の価格表を使います。詳しくは [AGENTS.md](AGENTS.md) を参照してください。

## 開発

必要なもの: Node.js、Rust（MSVC ツールチェーン）、Visual Studio Build Tools（C++）、WebView2。

```bash
npm install
npm run app:dev     # 開発モードで起動
npm run app:build   # インストーラーを作成（src-tauri/target/release/bundle/nsis/）
```

ログはすべてローカルで読み込み、外部に送信しません。ネットワークを使うのは、LiteLLM の価格表と為替レートの取得だけです
（設定でオフにできます）。
